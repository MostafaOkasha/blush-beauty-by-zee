# ChatGPT-generated images

Generated from the visual production pack (`blush_beauty_visual_asset_manifest.json`, 113 prompts). Each file name
starts with the asset ID of the prompt it answers. These are AI mood images: every one used on the site is wrapped
in `<Placeholder>` (or sits behind the hero's placeholder tag) and must be replaced by Zheen's own photography
before launch. None may be presented as her results.

Astro optimizes the imported files to WebP at build time, so only the images below that the site imports are
deployed.
